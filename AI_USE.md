# AI-use disclosure

AI assistance was used to inspect the supplied assessment brief, draft and implement application code, tests, UI, and project documentation, and to review public platform documentation. The generated implementation was exercised with local tests and connector simulations; a passing mock or simulation is not evidence of real-platform behavior.

No live destination accounts, API credentials, private user datasets, or external platform instances were supplied or used. The sample publication text and test data are synthetic. No external generative-AI API is called by the application.

All claims about platform connectivity, certification, metrics, audience size, destination quality, or catalogue research must be supported by later human review and verification against an owned instance or approved sandbox. Known unverified items are listed in [REPORT.md](REPORT.md) and [PROJECT_STATUS.md](PROJECT_STATUS.md).
