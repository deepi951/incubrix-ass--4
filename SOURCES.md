# Sources consulted

These sources informed the assessment scope and the documented API/container behavior. Their availability does not mean that a connector has been tested or certified against a live service.

## Assessment

- IncuBrix, *Assessment 4: Distribution Long Tail Destination Network Brief*, supplied PDF in the repository root; Appendix A connector contract, catalogue schema, and integration requirements.

## Platform API and deployment documentation

- Discourse API documentation and published OpenAPI specification: <https://docs.discourse.org/> and <https://docs.discourse.org/openapi.json>
- Lemmy official Docker installation guide: <https://join-lemmy.org/docs/administration/install_docker.html>
- Lemmy documentation's Docker Compose example: <https://raw.githubusercontent.com/LemmyNet/lemmy-docs/main/assets/docker-compose.yml>
- Lemmy Ansible example configuration: <https://raw.githubusercontent.com/LemmyNet/lemmy-ansible/main/examples/config.hjson>
- Forem API v1 reference (the API used by DEV): <https://developers.forem.com/api/v1>
- Ghost Admin API posts overview: <https://docs.ghost.org/admin-api/posts>
- Official Ghost container image information: <https://hub.docker.com/_/ghost>

## Scope and use

These documents were consulted as references for the assessment and development packaging. They are not evidence of end-to-end connector compatibility. No external platform instance was accessed, and no user credentials or content were sent to these services.
